获取失败，权限不足

系统问过一次「允许读取应用列表」，一旦点了不允许，它就不会再问第二次了，所以这里读到的是空的。

要恢复只能自己去系统设置里打开：设置 → 应用（应用管理）→ 找到本应用 → 权限 / 其他权限 → 允许「读取应用列表 / 获取应用列表」。
各品牌路径不一样，在设置顶上搜「应用列表」最快。

实在找不到，就清除本应用数据（或重装）后再打开一次，系统会重新问;这一次请选「允许」。
