添加小组件

内置和自定义用同一套样子：都是桌面同款毛玻璃卡。自定义的整个画面都由你的代码来画，不再加系统标题栏。

内置小组件

软件注册的小组件

还没有软件注册小组件。每个沧海软件都能在自己的 HTML 里按协议注册小组件，注册后会出现在这里。

自定义 HTML 小组件

提示：你的代码会铺满整个小组件，没有系统标题栏；根元素写 height:100% 就能撑满整面，里面的字和画会按小组件区域的实际大小自动等比缩放。不画背景时，透出的是和内置小组件一样的毛玻璃；想和内置小组件一个样子，背景用 var(--cw-bg)、文字用 var(--cw-ink) 就行（还有 --cw-sub 次文字、--cw-line 描边、--cw-chip 衬底、--cw-accent 海蓝、--cw-gold 浅金），深浅外观都会自动配好。代码在隔离框里运行，画布、按钮、脚本都可以正常用。
